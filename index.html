בשלב הזה התברר שבניית מודל תלת-ממדי בלבד אינה מספיקה כדי ליצור חוויה ויזואלית אמינה

SRN - Scene Representation Networks

SRN היה אחד הניסיונות הראשונים לייצג סצנה תלת-ממדית באמצעות רשת נוירונים. במקום לבנות מודל תלת-ממדי קשיח של הסביבה, הרעיון היה לאפשר לרשת ללמוד ייצוג רציף של הסצנה מתוך התמונות עצמן.

מיקום במרחב (x, y, z) + זווית צפייה (θ, φ) θזווית אופקית φזווית אנכית → צבע הפיקסל הנראה

המידע מוזן לרשת נוירונים מסוג MLP - רשת המורכבת ממספר שכבות Fully Connected.

p = (x, y, z) d = (θ, φ)
c = (R, G, B)

עבור כל נקודה במרחב הרשת חוזה איזה צבע אמור להופיע מאותה זווית צפייה,
ומתוך התחזיות האלו נבנית תמונה חדשה של הסצנה.

ב-SRN הייצוג של העולם אינו נשמר כאובייקטים או משטחים,
אלא כמידע שנלמד בתוך משקלי הרשת.

תצפית: תמונה בודדת פלט המודל: זוויות חדשות פלט המודל: גיאומטריה (לא מפוקח)

מתמונה בודדת של מכונית, הרשת ייצרה זוויות חדשות וגם פלט גיאומטרי שבו
הצבעים מקודדים את כיוון פני השטח התלת-ממדי - מתמונות 2D בלבד, בלי מודל 3D באימון.

NeRF

Neural Radiance Fields

במקום לבנות mesh או לאסוף תמונות - מאמנים רשת נוירונים אחת שמכירה את כל הסצנה. שואלים אותה על כל נקודה במרחב, מקבלים צבע וצפיפות, ומעבדים כל מבט שרוצים.

Mildenhall et al., ECCV 2020
הסצנה, אחרי שלמדנו אותה

אובייקט תלת-ממדי שהרשת מכירה

אחרי האימון, NeRF מחזיק את הסצנה כולה בתוך המשקלים שלו. גררו ימינה ושמאלה כדי להסתכל עליו מכל זווית - כל פריים הוא מבט שעובד מחדש מהמודל.
