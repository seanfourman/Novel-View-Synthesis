learned initializations for optimizing coordinate-based neural representations recent work in graphics and vision has shown the potential of representing complex low-dimensional signals using deep fully connected neural networks these networks take in an input coordinate and output a value of the signal at that coordinate for example a network can represent an image by taking a 2d pixel coordinate and outputting an rgb color this can be repeated for every pixel coordinate in a 2d grid to produce the entire image given a target image that we want the network to represent we compute the loss between the network's output and the target then use gradient descend to optimize the weights of the network over the course of many iterations the network learns to fit the target for certain applications this may require many gradient steps taking minutes or hours to converge in our paper we show how standard meta learning algorithms can find a better weight initialization and enables faster convergence in the image case we can learn initial weights theta 0 that work well to encode a variety of images each iteration of the meta learning algorithm trains the network to fit a target image and moves theta 0 in the direction of the converged weights over the course of this process theta 0 moves into a region of wave space and enables gradient descent to fit the target very quickly here is an example of fitting a network to the target image on the left the meta learn initialization only needs two gradient steps to fit the image but a standard randomly initialized networks takes significantly longer to converge to the same quality the most popular use case for these types of networks is representing 3d shapes or scenes as done in neural radiance fields or nerf we show results on a simplified version that takes in a 3d location and outputs the color and volume density when optimizing a nerf network given 25 input views of a chair our metal learned initialization allows for more rapid conversions we find that these metal learn weights not only speed up convergence but also encode a prior over a class of objects for example we can optimize a nerf network from these starting weights given only a single image of a chair which is impossible when using a standard initialization surprisingly we can still get this benefit even if the metal learning stage also doesn't have access to multiview information this means that the training data set only has a single view for each chair we denote this case as sv meta as opposed to mv meta where 25 images per chair are available during metal learning here we show a variety of objects each reconstructed from a single input image it is worth emphasizing that the only thing we've changed about the nerf optimization procedure is the initial weights surprisingly this is enough to capture a shape prior over a whole class of objects another failure mode of standard nerve is that it requires input images with the same environmental conditions such as lighting and camera exposure this prevents training on data sets like phototourism which contain images of famous landmarks taken by different people at different times we find that starting from a learned initialization generated using all photos of a landmark allows us to optimize a nerf to take on the appearance conditions from a single new photo
